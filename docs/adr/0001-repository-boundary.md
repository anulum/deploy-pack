# Repository boundary

Status: accepted for local tooling construction.

DEPLOY-PACK owns its repository validators now. Its planned scope is composition and verification of evidence-bound packages, per-unit authorized operation orchestration and attributed observed journals. Evidence generation, signing authority, fleet health judgment, model code and authoritative lineage storage retain their existing owners.

The planned package identifier is distinct from registered and qualified formats. Repository validation results cover infrastructure only; no domain package, release or actuator capability is declared before its full implementation.

Immutable package content precedes observed operations. Actual action authority is separate from health judgment or successful byte verification. Future changes add real public producers, separate consumers, target support, strict checks, tests, documentation and applicable benchmark parity in the same complete change.
